# Lüz Frequencies — publish this portfolio

This folder is a static website and is ready for GitHub Pages, Netlify, Vercel, or any static host.

## Fastest route
Upload the **contents of this folder** (not the outer folder) to a static hosting service.

## Important
- Keep `index.html`, `styles.css`, `script.js`, `content.js` together.
- Keep `assets/hero.jpg` inside the `assets` folder.
- The current package contains no Siren audio, CV, project audio/video, or project links because those files/URLs were not included in the uploaded ZIP. The site handles those missing items without dead playback errors.
- Use the `+` button in the footer to add them. For a public site, use the editor's **EXPORT COMPLETE SITE ZIP** after uploading your media.
